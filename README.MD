# Personal Projects

A collection of personal projects, automation tools, and utilities developed to solve practical problems and improve productivity.

## Projects

### 1. [YT Tools](./yt-tools/)

A collection of Python-based tools for YouTube-related tasks and workflow automation.

**Tech stack:** Python, uv

### 2. [PDF Tools](./pdf-tools/)

A command-line utility for working with PDF documents, including merging PDFs and images into PDFs, converting files, and compressing PDFs.

**Tech stack:** Python, uv

### 3. [Telegram Folder Uploader](./telegram-folder-uploader/)

A Python application for uploading files and entire folders to Telegram, with support for resumable uploads, session management, and command-line file selection.

**Tech stack:** Python, Telethon, uv

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rdChandrahaS/personal-projects.git
cd personal-projects
```

Navigate to an individual project and follow its README for setup and usage instructions.
